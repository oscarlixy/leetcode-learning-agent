# Behavior Evals

These evals replay the required coaching guardrails for:

- `first-session`
- `hint-escalation`
- `failing-code-review`
- `self-selected-problem`
- `session-resume`
- `review-scheduling`

Each scenario keeps a Chinese learner prompt plus `## Prompt`, `## Must`, and `## Must not` sections for manual or agent replay.
